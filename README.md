# Employee Manager – Angular + Spring Boot (Full Stack CRUD)

This is a full stack Employee Management web application built with **Angular** (frontend) and **Spring Boot** (backend). It supports basic CRUD operations:

- List all employees
- Add a new employee
- Update employee details
- View employee details
- Delete an employee

---

## Tech Stack

**Frontend**

- Angular 10
- TypeScript
- Bootstrap

**Backend**

- Spring Boot
- Spring Data JPA
- RESTful APIs
- MySQL
